Swim Stats privacy policy

Last updated: 19 November 2026

Swim Stats is a personal app used only by its author. This policy explains what it does with Google user data.

Data accessed

  • Google Health API (read-only): swim lengths, exercise sessions and heart rate.
  • Google Drive (drive.file): only files the app itself creates, used to store backups of the app's own database. It cannot see any other Drive files.

How the data is used

The data is used only to calculate and display swim statistics to the account owner. It is not used for advertising, profiling, or training machine-learning models.

Storage and sharing

Data is stored in a local database on the owner's own computer and backed up to the owner's own Google Drive. It is not sold, shared with, or transferred to any third party.

Retention and deletion

Data is kept until the owner deletes it. Access can be revoked at any time at myaccount.google.com/permissions.

Limited Use

Swim Stats' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
